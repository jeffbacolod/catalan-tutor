# CatalanTutor

CatalanTutor is an AI-powered Catalan language learning app that combines conversational AI, voice synthesis, and an animated avatar to create an immersive tutoring experience. Students speak or type in Catalan (or ask questions in English), and the tutor — powered by Anthropic's Claude — responds in Catalan with spoken audio generated by ElevenLabs and lip-synced to an animated avatar streamed via D-ID. Microphone input is handled entirely through the browser-native Web Speech API, requiring no third-party speech-to-text dependency.

## Architecture

The project is split into two independent packages: `client` (React + Vite) and `server` (Node.js + Express). They share a root `package.json` only for running both processes concurrently during development.

**Why an Express proxy?** All three external API keys (Anthropic, ElevenLabs, D-ID) live exclusively in the server's `.env` file and are never exposed to the browser. The client calls `/api/*` endpoints, which Vite proxies to `localhost:3001` in development. In production, the same Express server serves or sits behind the same domain, so the proxy pattern holds.

**React-Native-ready separation:** All business logic lives in `hooks/` and `services/` — pure JS with no DOM or browser-only assumptions (except `useSpeechRecognition`, which gracefully degrades). React components in `components/` are UI-only and receive data exclusively via props and hooks. This boundary makes it straightforward to swap the React renderer for React Native in the future.


## Services & Hooks

| File | Description |
|---|---|
| `services/claudeService.js` | Sends the full conversation history to the backend and returns the assistant's text reply. |
| `services/elevenLabsService.js` | Posts text to the backend TTS endpoint and returns a blob URL ready for `HTMLAudioElement`. |
| `services/didService.js` | Creates a D-ID animated talk from a source image and audio URL, and polls talk status. |
| `hooks/useSpeechRecognition.js` | Wraps the browser's native `SpeechRecognition` API, defaulting to `ca-ES`, with graceful error handling. |
| `hooks/useConversation.js` | Manages message history and orchestrates the full turn: user input → Claude → ElevenLabs → D-ID avatar stream. |

## Getting started

```bash
# 1. Copy and fill in API keys
cp .env.example .env

# 2. Install all dependencies (root + client + server)
npm run install:all

# 3. Start both dev servers
npm run dev
```

The React app will be available at `http://localhost:5173`. The Express API runs on `http://localhost:3001`.

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | Yes | Anthropic Claude API key — get one at console.anthropic.com |
| `ELEVENLABS_API_KEY` | Yes | ElevenLabs API key for text-to-speech — get one at elevenlabs.io |
| `DID_API_KEY` | Yes | D-ID API key (Base64-encoded `email:key`) — get one at d-id.com |
| `PORT` | No | Port for the Express server (default: `3001`) |
